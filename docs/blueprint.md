# **App Name**: Tex.io

## Core Features:

- Image Upload: Upload an image of text.
- AI Paraphraser: The LLM will examine the content of the image, determine its main ideas, and express the same ideas in a different and expanded form. The LLM uses a set of writing tools and editorial guidelines when processing text, ensuring the result maintains context and achieves proper style.
- Text Output: Displays the newly created text paragraph.
- Copy to Clipboard: Copy the generated text to the clipboard.

## Style Guidelines:

- Primary color: HSL 260, 90%, 40% (RGB hex: #4D00B3). A vibrant, saturated purple for a modern feel.
- Background color: HSL 260, 20%, 95% (RGB hex: #F0E5F7). Very light purple provides a gentle, uncluttered backdrop.
- Accent color: HSL 230, 90%, 60% (RGB hex: #3366FF). A brighter blue hue complements the purple.
- Font: 'Inter', a grotesque-style sans-serif suitable for both headlines and body text.
- Clean and modern layout with a focus on readability and ease of use.
- Use simple, clear icons for actions like 'upload' and 'copy'.
- Subtle animations when the text is generated, providing visual feedback to the user.
